# 🎓 Campus Recruitment System

A full-stack web application designed to simplify and digitize the campus recruitment process for students, recruiters, and administrators.

The system provides a centralized platform where students can manage their profiles and applications, recruiters can post and manage job opportunities, and administrators can oversee the complete recruitment process. 

---

## 🚀 Features

### 👨‍🎓 Student
- Student registration and login
- Create and manage student profile
- Add academic and personal information
- Browse available job opportunities
- View job requirements and eligibility
- Apply for suitable job opportunities
- Track application status
- Manage resume and profile information

### 🏢 Recruiter
- Recruiter registration and authentication
- Create and manage company profile
- Post new job opportunities
- Define job eligibility criteria
- View student applications
- Manage recruitment status
- Shortlist eligible candidates

### 🛠️ Admin
- Admin authentication
- Manage students and recruiters
- Monitor job postings
- Manage recruitment applications
- View overall recruitment activities
- Maintain the platform and user data
